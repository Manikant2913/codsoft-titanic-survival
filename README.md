# Titanic Survival Prediction

## CodSoft Data Science Internship - Task 1

This project predicts whether a Titanic passenger survived based on passenger information.

## Dataset

The project uses the Titanic dataset containing 891 passenger records.

## Features Used

- Passenger Class
- Age
- Number of Siblings/Spouses
- Number of Parents/Children
- Fare
- Gender
- Embarkation Port

## Machine Learning Model

Logistic Regression

## Data Processing

- Handled missing Age values using the median.
- Handled missing Embarked values using the mode.
- Converted categorical variables into numerical values.
- Split the dataset into 80% training and 20% testing data.

## Results

Accuracy: 80.45%

### Confusion Matrix

- True Negatives: 98
- False Positives: 12
- False Negatives: 23
- True Positives: 46
